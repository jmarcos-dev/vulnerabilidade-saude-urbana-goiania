# Vulnerabilidade em Saúde Urbana: Goiânia

Projeto de extensão densevolvido com o objetivo de analisar a vulnerabilidade em saúde urbana no municipio de Goiânia

## Objetivo

Investicar indicadores relacionados à saúde urbana em Goiânia e comparar esses dados com a percepção e o nível de conehcimento da população participante a pesquisa.

## Etapas
1. Pesquisa e levantemanto de dados
2. Coleta por meio de formulário
3. Análise dos dados
4. Elaboração do e-book
5. Divulgação por meio de vídeo

## Estrutura
-`docs/` - documentação do projeto
-`data/raw/` - dados originais coletados
-`data/processed` - dados tratados
-`analysis/` - scripts e notebooks de análise
-`ebook/` - materiais do e-book
-`video/` - materiais do vídeo
-`sources/` - registro das fontes utilizadas

## Tecnologias 
- Python
- Pandas
- Matplotlib
- PyCharm
- Git/Github

## Fontes
Os dados utilizados no projeto serão obtidos prioritariamente de fontes oficiais, como Fiocruz, DATASUS, IBGE, SNIS e Prefeitura de Goiânia.
